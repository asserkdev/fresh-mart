What is Fresh Mart?

Fresh Mart is an open-world game built in Godot 4. You run a supermarket inside a living city — order stock, hire staff, set prices, build your store, serve customers, and explore eight city districts full of residents, businesses, and opportunities. It's a supermarket simulator, city builder, sandbox construction game, and RPG combined into one.

🏪 Supermarket Simulation

36 products, 5 suppliers, full checkout, pricing, inventory management, deliveries, store reputation, and business analytics.

🔨 Sandbox Construction

Place shelves, refrigerators, checkout counters, lighting, and decorations on a grid. Changes persist when you leave and return.

🏙 Living City

Eight districts — Downtown, Old Town, Residential, University, Industrial, Waterfront, Suburban — each with residents and businesses.

⚔ Business RPG

Quests, character relationships, store progression, skill unlocks, and a main storyline connecting the city to your business.

How to Install & Run

  1. Install Godot 4

    Download Godot 4 for Windows (Standard version — not Mono). Extract it anywhere.

  2. Download the project

    Click the Download button above, or clone: git clone https://github.com/asserkdev/fresh-mart.git

  3. Open in Godot

    Launch Godot, click Import, navigate to the fresh-mart folder, and select project.godot.

  4. Run the game

    Press F5 or click the ▶ button in the top-right of the Godot editor. The main menu opens.

Save System

The game autosaves every 5 minutes (300 seconds) when the world has changed. Three rolling backups are maintained per save slot. If a save is corrupted, the game automatically loads the most recent valid backup and notifies you. All saves work offline — no account or internet required.

Save files are stored at: %APPDATA%\Godot\app_userdata\Fresh Mart\saves\

How to Install & Run

The installer handles everything automatically — including Godot if you don't have it.

  1. Download the installer

    Click the big download button above — get FreshMart_v7_Setup.exe (2.2 MB).

  2. Run the installer

    Double-click FreshMart_v7_Setup.exe. A wizard opens — click Next through the steps. Choose your install folder (defaults to %LOCALAPPDATA%\Programs\FreshMart).

  3. Godot installs automatically if needed

    If Godot 4 is not found, the launcher offers to install it via Windows Package Manager with one click. No manual download required.

  4. Play from the desktop shortcut

    A Fresh Mart shortcut with the game icon appears on your desktop. Double-click it to launch. The launcher finds Godot and starts the game immediately.

🏪 Supermarket

📦 Supply Chain

Finance panel, live inventory table with price-setting, supplier order system, pending orders tracker.

8-district world with 64×64m chunk streaming. Buildings with brick textures, roads, trees, street lights.

5 weather states — clear to heavy rain. GPU particle rain, fog, lighting shifts. Season-weighted probabilities.

Autosave every 5 minutes (only when changed). 3-backup crash recovery. Manual save with F. Multiple slots.

Procedural human characters — head, clothing, shoes — in different styles per role. No asset import required.

Save System

Autosaves every 5 real minutes — only when something actually changed. Three rolling backups per slot. On crash, the game loads the most recent valid backup automatically. All saves are local — no internet, no account.

Save location: %APPDATA%\Godot\app_userdata\Fresh Mart\saves\
